## 📚 Como Usar

1. **Clone ou baixe o script**
2. **Crie uma pasta no seu computador**
3. **Dentro dela, crie um arquivo com o nome `setup.sh`**
4. **Cole o script completo fornecido no GitHub**
5. **Execute com Git Bash:**
```bash
   ./setup.sh
```
