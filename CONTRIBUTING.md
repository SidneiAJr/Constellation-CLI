## 📋 Como Posso Contribuir?

### 🐞 Reportar Bugs
Encontrou um bug? Por favor, nos avise!

**Como reportar:**
1. Verifique se o bug já não foi reportado
2. Abra uma Issue no GitHub
3. Descreva o passo a passo para reproduzir o erro
4. Informe seu sistema operacional e versão do Bash
5. Adicione prints se possível

**Modelo de reporte:**
```markdown
**Descrição:** [O que aconteceu?]
**Passos para reproduzir:**
1. Executei o comando...
2. Selecionei a opção...
3. O erro apareceu...

**Comportamento esperado:** [O que deveria acontecer?]
**Sistema:** Windows/Linux/Mac + Git Bash
